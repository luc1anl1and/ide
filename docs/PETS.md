# Pets

Reva's desktop pet uses the **Codex pet format**, so any pet from [codex-pets.net](https://codex-pets.net/) works.

## Import a pet

Settings -> **Pet & PC control** -> **Import pet...** and pick a `.codex-pet.zip` / `.zip`, or **Import folder...** for an unpacked pet. You can also drop the folder into the pets folder yourself (**Open pets folder**).

A single **PNG / WebP / GIF picture** can be imported too; it becomes a static pet that bobs, hops and shakes.

## Format

A pet is a folder (or zip) with two files:

```
my-pet/
  pet.json
  spritesheet.webp      (or .png)
```

`pet.json`:

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "Optional text",
  "spritesheetPath": "spritesheet.webp",
  "spriteVersionNumber": 2,
  "kind": "creature",
  "pixelArt": false
}
```

`pixelArt: true` (or the word "pixel" in the id/name) switches off smoothing so pixel art stays crisp. `kind: "image"` makes a single-picture pet.

The spritesheet is a grid of **8 columns** with cells of **192 x 208** (a sheet may be scaled uniformly). Each row is one animation; frames are read left to right and the first empty cell ends the row:

| Row | Animation | Used when |
|---|---|---|
| 0 | idle | standing around |
| 1 | running right | walking to the right |
| 2 | running left | walking to the left |
| 3 | waving | greeting, opening the toolbar |
| 4 | jumping | an agent finished, being dropped |
| 5 | failed | an agent hit an error |
| 6 | waiting | an agent is thinking, or needs your approval |
| 7 | running | an agent is working / using your PC |
| 8 | review | an agent has just finished |
| 9-10 | look directions | reserved |

Missing rows fall back to idle. Reva ships one pet of its own ("Reva"), generated by `scripts/gen-pet.py` (needs Pillow).

## What the pet does

- Roams the screen (turn it off in Settings) and **all your monitors**, can be dragged anywhere, and its position is remembered.
- **Click it** to open the toolbar: **Ask AI** (pick the agent and chat, type a prompt, Enter to send) and **Activity** (every chat with its state: working, needs approval, ready, error; open or stop them).
- Speaks up when an agent finishes, needs approval or fails (click the bubble to jump to that chat).
- Shows a thought cloud while an agent is thinking, and a card with **Allow / Always allow / Deny** (or the answer options of a question, or Approve / Keep planning for a plan) whenever an agent needs your approval, so you can answer without opening the IDE.
- Shows what the AI is doing on your PC when you have allowed PC control: a purple AI cursor glides to every click, the pet walks over to keep it company, and there is a **Stop** button.
- Is a tool window: no taskbar button and not in Alt+Tab, only the IDE appears there.
- Closing the IDE window hides Reva to the tray instead of quitting, so the pet and running agents stay alive. Quit from the tray icon.
